## My Portfolio Website

This is my **personal portfolio website**, created to showcase my projects, skills, and creative work as a frontend developer. The website is designed with a modern UI, smooth animations, and a clean layout to highlight my abilities and style.

### Features

* Modern and responsive design
* Smooth animations and interactions
* Project showcase section
* About me & skills section
* Contact section for easy communication

### Technologies Used

* HTML
* CSS
* JavaScript
* GSAP (For Animations)
* Lenis (For Smooth Scrolling)

### Purpose

This portfolio was built to:

* Present my work professionally
* Improve my frontend development skills
* Practice modern UI/UX design techniques
* Create a personal brand identity online
